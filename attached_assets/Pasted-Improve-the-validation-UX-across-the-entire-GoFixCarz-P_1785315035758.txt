====================================
MOBILE NUMBER VALIDATION
====================================

When the user enters:
- Less than 10 digits
- More than 10 digits
- Invalid format
- Empty field

Show:
- Red border (#DC2626)
- Red warning icon inside the field
- Inline error message below the field

Examples:
"Please enter a valid 10-digit mobile number."
"Mobile number is required."

The error should disappear immediately after entering a valid number.
