Redesign the entire Job Card module to provide a guided, step-by-step workflow instead of displaying everything on a single screen.

The goal is to make the Job Card experience intuitive, efficient, and impossible to miss any important step. The flow should resemble professional workshop management systems, where the technician or garage owner completes one stage before moving to the next.

Do not change the existing backend APIs or business logic. Reuse the current APIs and only improve the UI, UX, navigation, and user flow.

## Objectives

- Convert the Job Card into a guided wizard.
- Break the process into logical steps.
- Show a clear progress indicator at the top (e.g., Step 1 of 8).
- Allow users to move forward and backward.
- Auto-save data after each completed step.
- Prevent users from skipping mandatory steps.
- Display validation messages before allowing users to continue.
- Preserve partially completed Job Cards so users can resume later.

## UI Improvements

Use a modern card-based interface.

Show:

- Stepper at the top
- Progress percentage
- Sticky Next button
- Sticky Previous button
- Smooth animated transitions
- Auto-save indicator
- Success message after each step

Use expandable cards instead of long forms.

Display only the information relevant to the current step.

Reduce scrolling as much as possible.

---

## User Experience

The technician should never feel overwhelmed.

Each screen should focus on one task only.

Large touch targets.

Minimal typing.

Dropdowns wherever possible.

Date pickers.

Searchable technician selector.

Searchable service selector.

Searchable parts selector.

Support barcode/QR scanning for parts if available.

---

## Validation

Required fields must be completed before moving forward.

Show inline validation.

Show clear error messages.

Auto-save after each successful step.

Allow users to leave and resume the Job Card later without losing data.

---

## Performance

Keep existing API integrations.

Do not change backend APIs.

Load data progressively.

Use loading skeletons.

Show offline state.

Handle API errors gracefully.

Optimize for both Android and iOS.

The final Job Card experience should feel like a guided service workflow used by professional automotive service platforms, making the process simple, fast, and highly efficient.
