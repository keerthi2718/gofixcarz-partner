Build a production-ready React Native mobile application using Expo and TypeScript.

Project Name:
mobile-gofixcarz-partner

Application Name:
GoFixCarz Partner

Purpose:
This is a Garage Owner mobile application for the GoFixCarz platform. The application should consume the existing FastAPI backend APIs.

Backend API Documentation:
https://api.gofixcarz.com/api/docs

IMPORTANT:
Read the API documentation completely before generating the application.

Use ONLY the Garage Owner related APIs.

DO NOT use:
- Customer APIs
- Vehicle APIs

Ignore every endpoint related to customers and vehicles.

Instead, build the application using the remaining Garage Owner APIs.

The application should automatically map the UI screens to the available APIs.
